# Fake Job Posting Detector 🚨

A Machine Learning web app that detects whether a job posting is **REAL** or **FAKE/SCAM** using NLP.

## Tech Stack
- Python
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit

## How to Run

```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
